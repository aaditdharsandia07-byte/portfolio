# Aadit Dharsandia — Portfolio

A responsive personal portfolio inspired by the interactive 3D keyboard portfolio concept from [Naresh-Khatri/3d-portfolio](https://github.com/Naresh-Khatri/3d-portfolio). This is a custom, lightweight implementation tailored to Aadit's supplied profile and projects; it is not a copy of the original source code.

## Run locally

No build tools or package installation are required.

1. Extract the ZIP.
2. Open `index.html` in a browser, or run a local server from this folder:
   - `python -m http.server 8000`
3. Visit `http://localhost:8000`.

## Included
- Interactive 3D-style skill keyboard (hover, focus or tap)
- Light and dark theme toggle
- Responsive mobile navigation
- Scroll reveal and progress animations
- HELIOS project poster and two certificate PDFs
- Email and LinkedIn contact links

## Before publishing
- Add a portrait in the reserved photo frame if desired.
- Add a GitHub profile URL when available.
- The contact link currently opens the visitor's email app; no server-side contact form is configured.
- The original template's private realtime backend is not included. The original template is MIT licensed; this custom implementation is independently written and links back to the inspiration repository.
